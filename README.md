# Encrypt Mode v1.0

## About this program

It facilitates the encryption process. You can encrypt and decrypt any file or text you want.

## How to use 

- Start the program with the `execute.bat` file;
- Select between `Encrypt` and `Decrypt`;
- Provide your password and provide your folder name. Your file will appear in a folder with the name we defined.
